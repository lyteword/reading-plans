# Bible Reading Plans in Markdown by LyteWord

## Overview 

This repository houses a curated collection of Bible reading plans, all written in Markdown. The plans are intentionally lightweight so they can be rendered directly by static‑site generators like **Hugo**, or converted to other formats (PDF, DOCX, etc.) with minimal effort. The goal is to provide end‑users with a set of ready‑to‑use plans that can be embedded in websites, printed, or integrated into other workflows.

Key plans included are:

- **Bible in a Year Plan** – a simple daily cadence that covers the entire Bible in 365 days.
- **Chronological Plan** – reads the Bible in the order the events occurred.
- **M’Cheyne Plan** – a classic plan that covers the Old and New Testaments through Family and Private readings.
- **And many others** – from short weekly plans to custom seasonal routes.

All plans are in pure Markdown, making them ideal for Hugo sites, Jekyll, MkDocs, or any tool that consumes Markdown.

## Why Markdown?

- ✅ *Portability:* View your devotions on any device without losing formatting.
- ✅ *Organization:* Quickly find and navigate by date, theme, or passage.
- ✅ *Customization:* Easily add highlights, notes, or bookmarks for deeper engagement.
- ✅ *Version Control:* Track changes, contribute, or collaborate with others if desired.
- ✅ *Easy to Share:* Publish or sync with note-taking apps and journals.
- ✅ *Accessibility:* Markdown is compatible with most modern software and assistive technologies.

## Usage

Clone or download the repository to access the Markdown files. Open them in any Markdown viewer or editor to read or repurpose the content.

### Converting to PDF

Using Pandoc or any similar Markdown‑to‑PDF tool:

```bash
pandoc plans/bible-in-a-year.md -o bible-in-a-year.pdf
```
